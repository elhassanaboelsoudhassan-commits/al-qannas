# Al-Qannas Landscape (القناص لاندسكيب)

برنامج لتحويل مخططات وتصاوير الحدائق والأماكن إلى رسومات هندسية (DXF) وثلاثية أبعاد (OBJ).

## المتطلبات (Requirements)
يجب تثبيت بيئة بايثون وتثبيت المكتبات المطلوبة:
```bash
pip install -r requirements.txt
```

## التشغيل (Running the App)
لتشغيل الخادم المحلي، قم بتشغيل الملف `run.bat` أو استخدم الأمر التالي:
```bash
uvicorn main:app --reload
```
ثم قم بزيارة الرابط: `http://127.0.0.1:8000`

## الميزات
- **واجهة مستخدم (UI):** واجهة عصرية وسهلة لرفع المخططات 2D وتحديد الأبعاد (الطول والعرض).
- **ملفات AutoCAD (DXF):** تصدير المخطط إلى ملف DXF يحتوي على طبقات مستقلة (الممرات، الأشجار، العشب، الجلسات).
- **نماذج 3D (OBJ):** تصدير مجسم ثلاثي الأبعاد بصيغة OBJ متوافق مع SketchUp و Planner 5D.
